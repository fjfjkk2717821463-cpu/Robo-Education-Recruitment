# 讲课设计：机器学习基础（10 分钟微课）

> 本文件是教学设计的**阶段一产出**：先把讲课逻辑定下来，再据此做幻灯片。
> 幻灯片见 `slides/`，完整推导与数据说明见 `topic/讲义.md`，课程级方案见 `topic/内训选题.md`。

## 〇、前提假设

用户未指定时按以下合理默认取值，若与实际课堂不符需要调整：

| 项 | 取值 |
| --- | --- |
| 课题 | 机器学习基础 |
| 听众已有基础 | 机协大一 / 大二成员；会一点 Python（变量、循环、函数），没接触过机器学习 |
| 时长 | 10 分钟（授课型 Demo） |
| 形式 | 投屏讲授 + 现场提问，不要求学员当堂写代码 |

**学完能做什么（可检验的动作）**

1. 说出训练一个模型必须有的四样东西，并指出缺了哪一样会出问题；
2. 用「朝低处走」这句话解释模型是怎么学会的，并说明学习率起什么作用；
3. 举出一个「训练指标很好看、模型其实没用」的具体情形。

**本课不讲什么**（写下来是为了控制认知负荷，不是偷懒）：微积分推导、深度学习网络结构、代码框架的安装与使用。

## 一、开场 1 分钟的地图脚本

> 今天要解决的是：**一个写不出判断规则的程序，怎么自己学会判断**。
> 分三块：**机器学习在做什么**、**模型是怎么学会的**、**怎么知道它真的学会了**。
> 最重要的是第二块——**模型是怎么学会的**。如果时间不够，这一块一定要记住。

讲完地图再进内容，开场不抛定义。

---

## 二、模块拆分

全课 3 个模块，每个模块只讲透一个核心观点，讲完立即小结。

| 模块 | 核心观点 | 时长 |
| --- | --- | --- |
| 模块一 · 机器学习在做什么 | 机器学习就是把「数据、模型、损失、优化」串成一条链 | 2 分钟 |
| 模块二 · 模型是怎么学会的 | 学习就是沿着损失下降的方向，一步步调整参数 | 4 分钟 |
| 模块三 · 怎么知道是真学会了 | 训练指标好看，不等于学到了能用的规律 | 2 分钟 |

---

## 三、问题链

每个模块内部按「为什么需要它 → 它是什么 → 怎么用 → 容易错在哪 → 和旧知识什么关系」推进，一问一答，答完就小结。

### 模块一

1. **为什么需要**：有些问题写不出 `if-else`——路口该不该转向、某个 PWM 对应多快的速度，规则列不完。
2. **它是什么**：监督学习 = 给一堆「输入 + 正确答案」，让程序自己反推那条规律。
3. **怎么用**：把这件事拆成四样东西——数据、模型、损失、优化。
4. **容易错在哪**：数据太少、标签记错、拿训练数据给自己打分。
5. **挂回旧知识**：和「用一条直线去拟合散点」是同一件事，只是把「拟合」叫成了「训练」。

### 模块二

1. **为什么需要**：知道了四样东西，还不知道「学」这个动作具体怎么发生。
2. **它是什么**：模型是一组待定的参数；损失是「所有样本误差平方的平均」，是一个数。
3. **怎么用**：站在损失曲线上，朝低处走一小步，反复走——这就是梯度下降。
4. **容易错在哪**：步长太大在最低点两侧越跳越远，步长太小半天挪不动。
5. **挂回旧知识**：和「下山找最低点」是同一件事，参数就是你的位置，损失就是海拔。

### 模块三

1. **为什么需要**：训练时损失明明很小，装到车上却完全不行。
2. **它是什么**：训练集、验证集、测试集的分工；过拟合与欠拟合。
3. **怎么用**：盯着训练误差和验证误差，看它们什么时候开始分岔。
4. **容易错在哪**：一个准确率 95% 的模型，可能一个该抓住的时刻都没抓住。
5. **挂回旧知识**：课后题做得好，不代表期末卷考得好。

## 四、具体 → 抽象 → 再具体

定义一律出现在例子之后。每个抽象概念都配一个具体例子，再拉回机器人场景。

| 概念 | 先给的具体例子 | 再抽象成 | 最后回到应用 |
| --- | --- | --- | --- |
| 特征与标签 | 给了 PWM 指令，小车实际跑多快 | 输入 x 与目标 y | 自己采一组小车数据 |
| 模型 | 一条直线的斜率与截距 | 一组待定的参数 | 预测没测过的 PWM |
| 损失 | 每个点的误差平方后取平均 | 一个可以比较大小的数 | 比较两组参数谁更好 |
| 训练 | 在抛物线上一步步往低处走 | 梯度下降 | 训练时盯着损失曲线 |
| 过拟合 | 9 次多项式把每个点都穿过去 | 训练误差小、验证误差大 | 上车前在没见过的数据上测 |

## 五、类比与例子

### 主类比：下山

| 结构成分 | 生活对应 |
| --- | --- |
| 参数 w、b | 你站在山上的位置 |
| 损失 L | 当前位置的海拔高度 |
| 梯度 | 脚下坡度最陡的方向 |
| 学习率 η | 每一步跨多大 |
| 最低点 | 拟合得最好的那组参数 |

**类比失效的边界**：真实的损失曲面不是一座光滑的山，可能有高原、峡谷和很多个坑。
所以实际训练要看损失曲线，不能只凭「往低处走一定对」的直觉。讲到这一句要主动说明，
否则学生会带着过于干净的印象离开。

### 第二个类比：做作业

| 概念 | 生活对应 |
| --- | --- |
| 训练集 | 课后题 |
| 验证集 | 模拟考 |
| 测试集 | 期末卷 |
| 过拟合 | 把课后题答案背下来了 |

**类比失效的边界**：课后题和期末卷通常出自同一本教材，分布是一致的；
而训练数据和现场数据可能根本不是同一个分布——这才是机器人上最常踩的坑，
也是这门课最想留下的印象。

## 六、互动节拍

每 5–10 分钟一次学生动作。问题只放页面，答案放备注，由讲者口头给出。

| 时间点 | 学生动作 | 这一步在检查什么 |
| --- | --- | --- |
| 0:40 | 举手判断：「算平均速度」和「判断该不该转向」分别属于哪一边 | 是否分清了「规则能写」和「规则写不出来」 |
| 2:40 | 投票：A 组参数的 MSE 比 B 组大还是小 | 是否理解损失是一个可以比较大小的数 |
| 6:00 | 预测：学习率调大十倍，损失会怎么变（先说出来再听讲解） | 是否理解步长对训练的作用 |
| 8:20 | 找错：这个准确率 95% 的模型，问题出在哪里 | 是否理解准确率在类别不平衡时会骗人 |

## 七、收尾

- 每个模块讲完，用固定的三句话小结：**这一块讲了什么 / 为什么重要 / 和下一块什么关系**（内容见幻灯片备注）。
- 全课结尾必须回到开场的三个问题：解决了吗？下一步做什么？
- 下一步行动（课下任务）：手写一次梯度下降并画出损失曲线；换三组学习率记录损失的变化；
  有条件的话拿自己小车的 PWM 与速度跑一遍标定。

## 八、时间分配（可直接照着讲）

| 模块 | 时长 | 核心观点 | 互动点 |
| --- | --- | --- | --- |
| 开场：封面 → 问题 → 目标 → 路线图 | 1.0 分钟 | 今天解决一个写不出规则的问题 | 举手判断两类问题 |
| 模块一 · 机器学习在做什么 | 2.0 分钟 | 数据 + 模型 + 损失 + 优化，四样缺一不可 | 投票：哪组参数更好 |
| 模块二 · 模型是怎么学会的 | 4.0 分钟 | 沿着损失下降的方向一步步调参数 | 预测：学习率调大会怎样 |
| 模块三 · 怎么知道是真学会了 | 2.0 分钟 | 训练指标好看不等于学到了规律 | 找错：95% 准确率的问题 |
| 总结与下一步 | 1.0 分钟 | 回到开场的三个问题 | 课下任务 |
| **合计** | **10.0 分钟** | | 4 次学生动作 |
