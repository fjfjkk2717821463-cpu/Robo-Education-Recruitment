# 讲课设计：机器学习基础（15 分钟微课 · 概念入门版）

> 本文件是教学设计的**阶段一产出**：先把讲课逻辑定下来，再据此做幻灯片。
> 幻灯片见 `slides/`，完整推导与调参细节见 `topic/讲义.md`，课程级方案见 `topic/内训选题.md`。
>
> **本轮定位调整**：参考《动手学深度学习》（PyTorch 第二版）第 1 章「引言」的框架
> （用数据编程 → 关键组件 → 各种机器学习问题 → 训练与测试、过拟合），
> 把课程重心从「一个模型怎么被训练出来」移到「机器学习在做什么、有哪些类型、怎么判断真的学会了」。
> 梯度下降的数值实验、收敛条件、精确率召回率的计算等细节下移到讲义，课堂上只保留概念与直觉。
>
> 分工不变：**内容层严谨、表达层易懂**；落到材料上是**页面易懂、备注严谨**。
> 每个概念走「生活例子 → 直觉解释 → 正式定义 → 条件边界 → 应用练习」，类比一律补
> 「类比只是帮助理解，不等于定义」。

## 〇、前提假设

| 项 | 取值 |
| --- | --- |
| 课题 | 机器学习基础（概念入门） |
| 听众已有基础 | 机协大一 / 大二成员；会一点 Python，没接触过机器学习；数学只要求看懂二维坐标图 |
| 时长 | 15 分钟（授课型 Demo） |
| 形式 | 投屏讲授 + 现场提问，不要求学员当堂写代码 |

**学完能做什么（可检验的动作）**

1. 用自己的话说清机器学习与传统编程的区别：为什么是「用数据编程」，而不是「写规则」；
2. 说出机器学习的四个关键组件，并说出监督学习、无监督学习、强化学习三者的区别；
3. 举出一个「训练指标很好看、模型其实没用」的具体情形，并指出这时该看哪个指标。

**本课不讲什么**（控制认知负荷，也写清楚严谨内容的去向）：微积分推导、梯度下降的收敛条件、
深度学习网络结构、正则化与其他优化器、精确率召回率的计算方法。这些都在讲义里，课后可自行查阅。

## 一、开场 1 分钟的地图脚本

> 今天要解决的是：**一个写不出判断规则的程序，怎么自己学会判断**。
> 全部 15 分钟，分三块：**机器学习在做什么**、**机器学习有哪些类型**、**怎么知道它真的学会了**。
> 第一块讲清「用数据编程」这件事和它的四个零件；第二块讲清常见的问题类型；
> 第三块讲清为什么训练得好不等于能用。

讲完地图再进内容，开场不抛定义。

## 三、问题链

### 模块一

1. **为什么需要**：有些问题写不出 `if-else`——判断该不该转向、某个 PWM 对应多快的速度，规则列不完。
2. **它是什么**：机器学习不写规则，而是准备大量「输入 + 答案」的例子，让程序自己把参数定下来。
3. **怎么用**：把这件事拆成四个关键组件——数据、模型、目标函数、优化算法。
4. **容易错在哪**：数据少、数据脏、数据不具代表性；目标函数选错；只拿训练数据给自己打分。
5. **挂回旧知识**：和「用一条直线拟合一堆散点」是同一件事，只是把「拟合」叫成了「训练」。

### 模块二

1. **为什么需要**：知道四要素还不够，还要知道自己面对的是哪一类问题，才能选对方法和指标。
2. **它是什么**：有标签 → 监督学习（预测数值是回归，预测类别是分类）；没标签 → 无监督学习（找结构）；
   要和环境互动、靠奖励学 → 强化学习。
3. **怎么用**：先问「有没有标准答案」，再问「输出是数值还是类别」，最后问「要不要边做边学」。
4. **容易错在哪**：把没有标签的问题硬当监督学习做；把分类问题当回归问题报指标；忽略同一任务可以有多种解法。
5. **挂回旧知识**：和「先看清题目问什么，再选公式」是同一件事。

### 模块三

1. **为什么需要**：训练时损失明明很小，装到车上却完全不行。
2. **它是什么**：训练集与测试集的分工；欠拟合与过拟合；指标要按任务选。
3. **怎么用**：同时看训练误差和测试误差，看它们什么时候开始分岔；类别不平衡时用召回率、精确率补上准确率看不到的部分。
4. **容易错在哪**：一个准确率 95% 的模型，可能一个该抓住的时刻都没抓住。
5. **挂回旧知识**：平时作业做得好，不代表期末卷考得好。

### 三层材料各放什么

| 位置 | 放什么 | 本课的具体落点 |
| --- | --- | --- |
| 页面 | 关键词、结构、图、案例标题、问题题干，以及**标注过的简化版** | 用数据编程对照图、四组件链条、样本表、两条候选直线、下山示意图、过拟合三联图、混淆矩阵 |
| 备注 | 正式定义、适用条件、反例、类比失效边界、口播顺序 | 参数 / 模型 / 模型族的定义、目标函数与损失函数的关系、监督学习三步骤、无监督与强化学习的边界、训练集与测试集的分工、精确率无定义的情形 |
| 讲义 | 完整推导、条件清单、数据来源、术语表、练习答案、延伸方向 | 梯度下降的推导与收敛条件、归一化的作用、各类型问题的完整清单（标记 / 搜索 / 推荐 / 序列学习）、数据来源与复现方式 |

### 本课做了哪两处简化，怎么补回来

| 简化 | 页面上怎么标注 | 讲的时候怎么补严谨 |
| --- | --- | --- |
| 优化算法只讲梯度下降的直觉，不讲怎么求导 | 第 10 页底部标注「示意：固定 b、只调 w，且只讲直觉」 | 说明这只是众多优化算法里最基本的一种；梯度是「每个参数小幅变动时损失往哪动」的方向 |
| 目标函数只举平方误差（MSE） | 第 9 页只出现 MSE | 说明目标函数不只有 MSE：分类问题常用错误率或交叉熵，有些目标不好优化时会换成替代目标 |

**判断标准**：简化只允许降低表达难度，不允许改变结论。上面两处都没有改变结论。

## 五、具体 → 抽象 → 再具体

| 概念 | 先给的具体例子 | 再抽象成（正式定义） | 条件边界 | 最后回到应用 |
| --- | --- | --- | --- | --- |
| 用数据编程 | 给一堆 PWM 与实测速度 | 不写规则，用数据定参数的程序 | 前提是「有大量例子」且「规则难写」；没有数据就没有这门技术 | 自己采一组小车数据 |
| 数据 | 一行 PWM + 实测速度 | 样本、特征、标签；通常假设独立同分布 | 数据要多，也要对：垃圾进垃圾出；不具代表性、类别不均衡会带来系统性偏差 | 换场地、换光照再采一遍 |
| 模型 | 一条直线的斜率与截距 | 一组待定参数确定的输入输出映射 | 线性形式只在近似线性时合适；深度模型是多层转换 | 预测没测过的 PWM |
| 目标函数 | 两条候选直线哪条更贴合 | 把模型好坏压缩成一个数；习惯上取越小越好的损失函数 | 回归常用平方误差，分类常用错误率；不好优化时换替代目标 | 比较两组参数谁更好 |
| 优化算法 | 在损失曲线上朝低处走 | 搜索使目标函数变小的参数；最基本的是梯度下降 | 学习率太大发散、太小太慢；非凸时不一定到全局最低点 | 训练时盯着损失曲线 |
| 问题类型 | 判断该不该转向 / 给样本分组 / 让小车试错走迷宫 | 监督学习、无监督学习、强化学习 | 有没有标签是分界线；同一任务可以换学习方式 | 先给任务分类再选方法 |
| 泛化 | 1 次、3 次、9 次多项式拟合同一组点 | 训练误差与测试误差的分工 | 测试集只能用一次；训练分布和现场分布不一致是机器人上最常见的坑 | 上车前在没见过的数据上测 |
| 评价 | 永远输出「不需要转向」的模型 | 准确率、召回率、精确率的定义 | 类别不平衡时准确率失真；不分正负例时精确率无定义 | 按两类错误的代价选阈值 |

## 六、类比与例子（含失效边界）

所有类比都要补一句「**类比只是帮助理解，不等于定义**」。

### 主类比：参数是旋钮

| 结构成分 | 生活对应 |
| --- | --- |
| 参数 | 机器面板上的旋钮 |
| 模型的形式 | 旋钮接在哪台机器上（由人选好） |
| 训练 | 反复拧旋钮，直到输出让人满意 |

**失效边界**：旋钮暗示「一次就能拧到位」，真实训练是一步步试出来的，而且每一步都要算一遍数据。

### 第二个类比：下山

| 结构成分 | 生活对应 |
| --- | --- |
| 参数 | 你站在山上的位置 |
| 损失 | 当前位置的海拔 |
| 梯度 | 脚下坡度最陡的方向 |
| 学习率 | 每一步跨多大 |

**失效边界**：真实的损失曲面不是一座光滑的山，可能有高原、峡谷和很多个坑；
梯度下降只保证在凸的、光滑的面上收敛到全局最低点。

### 第三个类比：做作业与考试

| 概念 | 生活对应 |
| --- | --- |
| 训练集 | 平时作业 |
| 验证集 | 模拟考 |
| 测试集 | 期末卷 |
| 过拟合 | 把作业答案背下来了 |

**失效边界**：作业和期末卷通常出自同一本教材，分布是一致的；而训练数据和现场数据可能根本不是同一个分布——
这才是机器人上最常踩的坑，也是本课最想留下的印象。

## 八、收尾

- 每个模块讲完，用固定的三句话小结：**这一块讲了什么 / 为什么重要 / 和下一块什么关系**
  （三个模块各有一页独立小结）。
- 全课结尾回到开场的三个问题，并给出下一步行动：用自己的话复述四组件；
  给身边的三个任务各贴一个类型标签；有条件的话，拿小车的 PWM 与速度数据跑一遍最小二乘拟合，
  再用讲义里的梯度下降跑一次，对比两条曲线。
