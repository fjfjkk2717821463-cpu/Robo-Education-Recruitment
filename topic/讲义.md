## 一、概念地图：机器学习在做什么

本节按《动手学深度学习》（PyTorch 第二版）第 1 章「引言」的框架组织：**用数据编程 → 四个关键组件 →
各种机器学习问题 → 训练与测试、过拟合**。表述为本课自己重写，不是原文摘抄。

### 1. 从「写规则」到「用数据编程」

传统程序把规则写死：人要把所有边界情况都想到，程序也不会因为见得多而自己变好。
但有些问题的规则写不出来（判断该不该转向），或者写全了要几百条、还得天天改。

机器学习换了一条路：**不写规则，而是准备大量「输入 + 正确答案」的例子，让程序自己把参数定下来**。
这种用数据集来确定程序行为的做法，可以叫**用数据编程**。

几个必须分清的词：

| 词 | 含义 |
| --- | --- |
| 参数 | 程序里由数据决定、而不是由人写死的数。可以想成机器面板上的旋钮 |
| 模型 | 一组参数确定下来的输入到输出的映射 |
| 模型族 | 调整参数能得到的所有映射的集合 |
| 学习算法 | 用数据从模型族里挑出参数的算法 |

一次典型训练分四步：**随机初始化参数 → 取一批样本 → 调整参数让表现变好 → 重复前两步**，
直到表现令人满意。要点是：它不是一次算完，而是反复迭代。

### 2. 四个关键组件

不管哪一类机器学习问题，都会遇到这四个组件：

| 组件 | 一句话解释 | 常见误解 |
| --- | --- | --- |
| 数据 | 一批样本，每个样本由特征和标签组成（无监督学习没有标签） | 不是「数据越多越好」，数据还要有代表性 |
| 模型 | 把输入变成输出的函数，里面带着待定的参数 | 模型不等于训练好的结果，它是「函数的形式」 |
| 目标函数 | 衡量模型好坏的函数；习惯上取越小越好，这时也叫损失函数 | 目标函数不只有平方误差，分类问题常用错误率 |
| 优化算法 | 在参数空间里搜索，让目标函数变小的算法 | 梯度下降只是最基本的一种，不是唯一一种 |

关于目标函数还有两点要补：一是把它定义成「越大越好」完全可以，只是差一个符号；
二是有些目标（比如错误率）不好直接优化，实践中会换成一个更容易优化的**替代目标**。

### 3. 各种机器学习问题

判断一个任务属于哪一类，先问两句话：**数据有没有标准答案？要不要和环境互动？**

| 类型 | 判断依据 | 典型任务 |
| --- | --- | --- |
| 监督学习 | 每个样本都带标签 | 回归（输出数值，如预测速度）、分类（输出类别，如判断该不该转向） |
| 无监督学习 | 没有标签 | 聚类（把相似样本归到一起）、降维（用少数几个量概括主要变化） |
| 强化学习 | 与环境交互，靠奖励改进 | 让智能体在试错中学会一串动作，比如走迷宫、对弈 |

监督学习还有几种常见形态，本课不展开，但值得知道：
**标记问题**（一个样本可以同时有多个标签，比如一篇文章同时属于「机器学习」和「编程语言」）、
**搜索**（输出排好序的子集，顺序本身有意义）、**推荐系统**（给每个用户排一个个性化列表）、
**序列学习**（输入输出都是变长序列，比如语音识别、机器翻译）。

无监督学习不等于「没有目标」：它照样要有目标函数，只是目标从「逼近标签」换成了「把结构找出来」。
强化学习拿到的是奖励而不是标准答案，环境甚至不会告诉你哪一步动作带来了奖励，
所以它还要解决「功劳分配」的问题。

### 4. 训练集、测试集与过拟合

- 训练集用来调整参数，测试集用来评估模型，两者不能混用；
  验证集夹在中间，用来比较模型、调超参数。
- 训练表现好、测试表现差，叫**过拟合**：模型把训练数据里的噪声也背下来了。
- 两边都差，叫**欠拟合**：模型太简单，连训练数据里的规律都没抓住。

常用的类比是「平时作业 / 模拟考 / 期末卷」对应「训练集 / 验证集 / 测试集」。
**类比只是帮助理解，不等于定义**：真实场景里训练数据和现场数据可能根本不是同一个分布，
这才是机器人上最常踩的坑。

### 5. 数据本身的两个坑

1. **垃圾进，垃圾出**：特征记错、单位混用，模型学到的就是错的规律，而且会以很高的置信度输出。
2. **数据不具代表性**：训练数据里从没出现过的情况，模型遇到就会失灵；类别严重不均衡时，
   模型只要一直输出多数类就能拿到很高的准确率。如果把带历史偏差的数据拿来训练，
   还会把这种偏差一起自动化。

在机器人上，第 2 条的具体表现就是：**实验室里采的数据和赛场上的数据分布不一样**。

### 6. 深度学习在这张地图上的位置

深度学习是机器学习的一个分支：它的模型由多层数据转换叠起来，每一层提供一个层次的表示，
所以也叫多层次的**表示学习**。它最显著的特点是**端到端训练**——
不再由人手工设计特征，而是把特征提取和模型放在一起调。

它最近十几年的进展主要来自三件事：**大规模数据、便宜且强大的算力（尤其是 GPU）、好用的开源框架**。
本课不展开深度模型，只要知道它是上面这张地图里的一个位置就够了。

两组数据都由 `assets/make_figures.py` 在同一个固定随机种子下生成。**「换成真实数据」这句话只适用于第一组**：
把标定数据换成自己采的 PWM 与速度两列，拟合、算损失、梯度下降这三段代码一行都不用改；

### 1. 电机标定数据

**数据怎么来的**：给小车一个 PWM 指令，量出它实际跑出的速度，两者大致成线性关系，
但每次测量都会带随机误差。生成脚本 `assets/make_figures.py` 里的核心四行是：

```python
rng = np.random.default_rng(11)                        # 固定随机种子，保证可复现
PWM = np.linspace(1000.0, 2000.0, 18)                  # 18 个指令值
SPEED_TRUE = 0.40 * (PWM - 1000.0) + 30.0              # 真实规律
SPEED = SPEED_TRUE + rng.normal(0.0, 12.0, PWM.size)   # 叠加测量噪声
```

- 18 个样本，PWM 从 1000 到 2000；
- 真实规律是「PWM 每增加 1000，速度增加 400」，基准速度 30 mm/s；
- 噪声标准差 12 mm/s，模拟实际测量时的抖动。
- 这 18 行数据已经导出成 `assets/pwm_speed.csv`（两列：`pwm`、`speed_mm_s`），
  直接读它就能复现讲义和幻灯片里的每一个数字；换种子会让数字全部变化。

### 2. 过拟合演示数据

第 18 页的三联图用的是另一组数据：在 [−1, 1] 上均匀取 14 个训练点，
真实函数是 y = 0.62·sin(3x)，再叠加标准差 0.09 的噪声；验证集在同一条曲线上另取 60 个点。
这组数据的作用是让「1 次太简单、3 次刚好、9 次把噪声也学进去」三种情况同时出现在一张图上。

**为什么要说明是合成的**：合成数据可以精确知道「真实规律」，才能判断模型学得好不好；
但它的噪声分布比真实世界干净得多。**把它当成真实数据的替代品会得出过于乐观的结论**。
要换成真实数据，只需要把脚本里的 `PWM`、`SPEED` 换成自己采集的两列数据，
其余代码（拟合、算损失、梯度下降）一行都不用改。

**怎么采真实数据**：在直线上标出 2 米，给小车一串 PWM 值，每个值跑三次，
用秒表记时间、算平均速度，每个 PWM 取三次的平均值。同一个 PWM 三次之间的差异，
就是这台车的真实噪声水平。

## 三、完整推导（可选深入）

### 1. 模型与损失

线性模型预测速度：

$$
\hat{y}_i=w x_i+b
$$

其中 xᵢ 是第 i 个样本的输入（这里用的是归一化后的 PWM），ŷᵢ 是预测值。
均方误差把 18 个样本的误差合成一个数：

$$
L(w,b)=\frac{1}{N}\sum_{i=1}^{N}\left(w x_i+b-y_i\right)^2
$$

取平均是为了让损失与样本数量无关，平方是为了让正负误差不互相抵消、并放大较大的误差。

### 2. 求梯度

对 w 和 b 分别求偏导：

$$
\frac{\partial L}{\partial w}=\frac{2}{N}\sum_{i=1}^{N}\left(w x_i+b-y_i\right)x_i
$$

$$
\frac{\partial L}{\partial b}=\frac{2}{N}\sum_{i=1}^{N}\left(w x_i+b-y_i\right)
$$

梯度里每一项都是「预测减真实」的误差乘上对应的输入。误差为正说明预测偏大，
就往减小的方向调；误差为负就往反方向调。

### 3. 梯度下降的更新式

$$
w\leftarrow w-\eta\frac{\partial L}{\partial w},\qquad
b\leftarrow b-\eta\frac{\partial L}{\partial b}
$$

η 是学习率，决定每一步走多大。课堂上看损失随参数变化的曲线，讲的就是这个式子的几何含义。

### 4. 为什么课堂上把 b 固定住

同时调 w 和 b，损失是三维空间里的一张曲面（两个参数加一个损失值），画在纸上看不清楚。
为了让学生看清「一步步往低处走」，幻灯片里把 b 固定在最优值（b = 速度均值 232.28），
只调 w，并把输入归一化成 x = (PWM − 1500) / 500。此时 L 是关于 w 的二次函数：

$$
L(w)=L_{\min}+\tfrac{1}{2}c\left(w-w^\ast\right)^2,\qquad
w^\ast=\frac{\sum_i x_i\left(y_i-b\right)}{\sum_i x_i^2},\qquad
c=\frac{2}{N}\sum_i x_i^2
$$

这里的 c = 2·mean(x²) 是 L 对 w 的**二阶导**（曲率），所以顶点式里的二次项系数是 c/2，不是 c。
两者差一个 2 倍，混用会让损失的计算结果和曲线对不上。
二次函数只有一个最低点，用初中的抛物线就能解释清楚梯度下降。

**为什么这一步要做归一化**：不归一化也能算，但 x 在 1000 到 2000 这个量级上时，
c = 2·mean(x²) 会大六个数量级，学习率必须小到千万分之一才能收敛。
归一化让 c 回到 1 附近，学习率好选、曲线也好画。归一化不改变问题本身，只改变 w 的数值含义：
同一个拟合结果，输入放大 500 倍，w 就缩小 500 倍——这就是幻灯片里 w 一会儿是 0.398、
一会儿是 198.77 的原因。

### 5. 学习率为什么会发散

把更新式代入二次函数，误差会按固定比例缩小或放大：

$$
w_{t+1}-w^\ast=\left(1-\eta c\right)\left(w_t-w^\ast\right)
$$

所以只要 **0 < η·c < 2** 就会收敛，超过 2 就会越走越远。

**边界情况**：η·c = 2 正好落在分界线上，此时 1 − ηc = −1，误差每步只变号、大小不变，
参数会在最低点两侧一直来回跳，既不收敛也不发散。这也是「学习率太大训练会崩」的数学原因。

## 五、术语表

| 术语 | 一句话解释 |
| --- | --- |
| 样本 | 一次观测，表格里的一行 |
| 特征 | 用来预测的输入，记为 x |
| 标签 | 想要预测的目标，记为 y |
| 用数据编程 | 不写规则，用数据集来确定程序行为（也就是定参数）的做法 |
| 监督学习 | 训练数据里带着正确答案的学习方式，学的是从输入到标签的映射 |
| 无监督学习 | 训练数据没有标签，目标变成从数据本身找结构（例如聚类） |
| 强化学习 | 智能体与环境反复交互、靠奖励信号改进策略的学习方式 |
| 回归 | 监督学习的一种，输出是一个连续数值，例如预测速度 |
| 分类 | 监督学习的一种，输出是一个类别，例如判断该不该转向 |
| 聚类 | 最典型的无监督任务：没有标签，把相似的样本归到一起 |
| 参数 | 模型里由训练决定的数，例如 w 和 b |
| 模型 | 一组参数确定下来的输入到输出的映射 |
| 模型族 | 调整参数能得到的所有映射的集合 |
| 学习算法 | 用数据从模型族里挑出参数的算法 |
| 超参数 | 由人设定的数，例如学习率、多项式次数 |
| 目标函数 | 衡量模型好坏的函数；习惯上取越小越好，这时也叫损失函数 |
| 损失函数 | 目标函数取「越小越好」时的叫法 |
| 均方误差 | 误差平方后的平均值，最常用的回归损失 |
| 梯度 | 损失上升最快的方向，反着走就是下降方向 |
| 梯度下降 | 沿着负梯度方向反复小步调整参数的训练方法 |
| 学习率 | 每一步走多远的系数，记作 η |
| 归一化 | 把不同量级的特征缩放到相近范围，便于训练 |
| 训练集 | 用来调整参数的数据 |
| 验证集 | 用来比较模型与调超参数的数据 |
| 测试集 | 只在最后评估一次的数据 |
| 泛化 | 在没见过的数据上的表现 |
| 欠拟合 | 模型复杂度不足，训练误差本身就明显偏高，验证误差也高 |
| 过拟合 | 模型把训练数据里的噪声也学进去了，训练误差很低、验证误差明显变大 |
| 独立同分布 | 每个样本都来自同一套规律、且互不影响的假设，很多方法默认它成立 |
| 表示学习 | 自动寻找合适的数据表示方式；深度学习是多层次的表示学习 |
| 端到端训练 | 不分别调各个部件，而是把整个系统放在一起联合调整 |
| 准确率 | 预测正确的比例，类别不平衡时会失真 |
| 召回率 | 该被抓住的样本里实际抓住了多少，等于 TP / (TP + FN) |
| 精确率 | 被判为某类的样本里有多少是真的属于这一类，等于 TP / (TP + FP)；从不预测正类时分母为 0，无定义 |

## 六、条件与边界清单

页面为了易懂做了简化，条件补在这里。讲课时至少要口头说到「边界与反例」那一列里的内容。

| 概念 | 成立条件 | 边界与反例 |
| --- | --- | --- |
| 用数据编程 | 规则难写或容易变，而且能拿到足够多、有代表性的例子 | 规则清楚、数据又少时，直接写规则更划算；没有数据就无从谈起 |
| 数据（样本、特征、标签） | 样本之间大致独立同分布，特征确实与任务相关 | 数据来源有偏、类别不均衡、单位混用都会让模型学到错的规律；无标签时就没有「标签」这个词 |
| 监督学习 | 训练数据带标签，任务是预测 | 没有标签就是无监督学习，损失函数的定义方式不同；只讲监督学习时不能把「机器学习」当成同义词 |
| 分类与回归 | 分类的标签是有限几个类别，回归的标签是连续数值 | 把分类当回归报指标（或反过来）会得出错误结论；有序类别（如星级）介于两者之间，要按具体任务判断 |
| 无监督学习 | 有数据、没有标签，目标是找结构 | 「没有标签」不等于「没有目标函数」；聚类结果没有唯一正确答案，需要人来解释 |
| 强化学习 | 能反复与环境交互、能拿到奖励信号、允许试错 | 试错代价高的场景（真车、医疗）要先在仿真里练；奖励设计得不好，模型会学出奇怪的行为 |
| 目标函数 | 目标确实代表我们想要的「好」 | 目标函数可以定义成越大越好；优化目标不等于真实目标，「指标好看但没用」往往就出在这里 |
| 线性模型 y = w·x + b | 输入与输出大致成线性关系 | 数据弯了就要换模型形式；但「模型是一组待定参数」这句话仍然成立 |
| 均方误差 MSE | 标签是连续数值（回归）；误差大小真的代表代价 | 分类问题不用 MSE，用交叉熵；MSE 对大误差特别敏感，一个离群点就能把损失拉高 |
| 损失小 = 模型好 | 只在训练集上成立，且只对同一批数据比较 | 训练损失小不代表泛化好；换一批数据结论可能完全反过来 |
| 梯度下降 | 学习率合适；本课讨论的是凸的、光滑的二次损失 | 非凸、非光滑时「往低处走」不一定到全局最低点；同时调两个参数时是一个三维曲面，不是一条抛物线 |
| 学习率收敛 | 0 < ηc < 2，其中 c 是损失对参数的二阶导 | ηc = 2 正好在边界上：只来回跳、不收敛也不发散；ηc > 2 发散 |
| 训练集 / 验证集 / 测试集 | 三者互不重叠；验证集用来调超参数 | 测试集只能用一次；反复用测试集挑模型，它实际上就变成了验证集 |
| 过拟合与欠拟合 | 必须同时看训练误差和验证误差 | 只看训练误差判断不了；验证误差变大也可能是因为验证集太小或分布不同 |
| 准确率 | 两类样本大致均衡、两种错误代价相当 | 类别不平衡时会严重失真（95% 准确率、0 召回率的例子） |
| 精确率 | 至少有一次正类预测，分母 TP + FP 不为 0 | 从不预测正类时精确率无定义，不能写成 0% |
| 「漏报比误报贵」 | 只在这个转向任务里成立 | 换一个任务可能反过来：误触发急停同样危险，这时要按两类错误的代价选阈值 |

## 七、练习与答案

第 1–7 题配合第三节的计算，动笔就能验算；第 8–10 题是概念题，跟完课就能做，建议先做这三题。

1. **给三个样本 (0, 1)、(1, 3)、(2, 5)，用最小二乘拟合一条直线，MSE 是多少？**
   答案是 y = 2x + 1，三个点都落在直线上，MSE = 0。这题说明：当数据恰好符合线性关系时，
   最小二乘能给出精确解。

2. **如果把学习率从 0.80 改成 0.05，损失曲线会变成什么样？**
   仍然单调下降，但下降得非常慢——8 步之后损失还有 1351.9，远没到最低点。
   现象是「训练看起来在进步，但一直收敛不了」。

3. **训练误差 0.001、验证误差 67.314，说明什么？下一步怎么办？**
   典型的过拟合：模型把 14 个训练点连同噪声一起背下来了。
   下一步是降低模型复杂度（比如把 9 次多项式换回 3 次）或增加数据量。
   （正则化也能缓解过拟合，但它超出本课范围，这里只作为延伸提示。）

4. **一个模型准确率 95%、召回率 0%，能装到车上吗？**
   不能。它只是学会了永远输出多数类（「不需要转向」），一个该转向的时刻都没抓住。
   在机器人上，漏报往往比误报贵得多，所以要看召回率而不只是准确率。

5. **为什么训练前常要把特征归一化？**
   不同特征量级差太多时，损失曲面会变成一个又长又窄的峡谷：在陡的方向上稍微一动就飞出去，
   在平的方向上走半天也不动，很难选到一个对两个方向都合适的学习率。
   把特征缩放到相近范围，曲面接近圆形，一个学习率就能同时照顾所有方向。
   用本节的数字说更直接：归一化后曲率 c = 0.745，学习率上限是 2.68；
   不归一化时 c 会大六个数量级，学习率必须小到千万分之一。

6. **如果学习率正好取到边界，会发生什么？**
   取 ηc = 2 时，误差每步只变号、大小不变，参数会在最低点两侧一直来回跳：
   既不收敛到最低点，也不像 ηc > 2 那样越走越远。这说明「收敛」和「发散」之间还有一条边界线，
   不是非黑即白。

7. **一个模型准确率 95%、召回率 0%，它的精确率是多少？**
   精确率**没有定义**，不是 0%。因为这个模型从不预测正类，精确率的分母 TP + FP = 0 + 0 = 0。
   能算的是准确率 95%、召回率 0%。这题说明：指标的分母为 0 时要单独说明，不能直接写 0。

8. **下面三个任务各属于哪一类？**（1）给一组房屋的面积、卧室数，预测房价；
   （2）给一批用户浏览记录，没有标签，把行为相似的用户归到一起；（3）让一个程序反复下棋，
   赢了加分、输了扣分，逐步提高棋力。
   （1）监督学习里的回归——每个样本都有房价作为标签，输出是连续数值；
   （2）无监督学习里的聚类——没有标签，目标是把相似的样本归到一起；
   （3）强化学习——没有标准答案，只有奖励信号，而且每一步都会影响后面的局面。

9. **「模型在训练集上准确率 99%，所以可以上车了」——这句话错在哪？**
   错在只看了训练集。训练集上的表现只说明「背得熟不熟」，要看它在没见过的数据（验证集或测试集）上表现如何。
   如果训练误差很小、测试误差明显变大，就是过拟合；两个都大则是欠拟合。此外还要确认训练数据的分布
   和现场一致——只在实验室地板上采过数据，到了赛场照样会失灵。

10. **为什么说机器学习是「用数据编程」，而不是「不编程」？**
    因为人仍然要做很多决定：确定输入输出是什么、选哪一类问题、挑模型族、定目标函数、准备并检查数据。
    机器学习只是把「写具体规则」这一步换成了「用数据把参数定下来」；
    数据有偏、目标函数选错、任务类型判断错，程序照样会给出错误的答案。
