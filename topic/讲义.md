## 一、数据说明

幻灯片刻意没有用现成数据集，而是用一组**自己合成的电机标定数据**，因为它的量级小、
物理含义清楚、也能完整复现。

**数据怎么来的**：给小车一个 PWM 指令，量出它实际跑出的速度，两者大致成线性关系，
但每次测量都会带随机误差。生成脚本 `assets/make_figures.py` 里的核心三行是：

```python
PWM = np.linspace(1000.0, 2000.0, 18)              # 18 个指令值
SPEED_TRUE = 0.40 * (PWM - 1000.0) + 30.0          # 真实规律
SPEED = SPEED_TRUE + np.random.normal(0.0, 12.0, 18)   # 叠加测量噪声
```

- 18 个样本，PWM 从 1000 到 2000；
- 真实规律是「PWM 每增加 1000，速度增加 400」，基准速度 30 mm/s；
- 噪声标准差 12 mm/s，模拟实际测量时的抖动。

**为什么要说明是合成的**：合成数据可以精确知道「真实规律」，才能判断模型学得好不好；
但它的噪声分布比真实世界干净得多。**把它当成真实数据的替代品会得出过于乐观的结论**。
要换成真实数据，只需要把脚本里的 `PWM`、`SPEED` 换成自己采集的两列数据，
其余代码（拟合、算损失、梯度下降）一行都不用改。

**怎么采真实数据**：在直线上标出 2 米，给小车一串 PWM 值，每个值跑三次，
用秒表记时间、算平均速度，每个 PWM 取三次的平均值。同一个 PWM 三次之间的差异，
就是这台车的真实噪声水平。

## 二、完整推导

### 1. 模型与损失

线性模型预测速度：

$$
\hat{y}_i=w x_i+b
$$

其中 xᵢ 是第 i 个样本的输入（这里用的是归一化后的 PWM），ŷᵢ 是预测值。
均方误差把 18 个样本的误差合成一个数：

$$
L(w,b)=\frac{1}{N}\sum_{i=1}^{N}\left(w x_i+b-y_i\right)^2
$$

取平均是为了让损失与样本数量无关，平方是为了让正负误差不互相抵消、并放大较大的误差。

### 2. 求梯度

对 w 和 b 分别求偏导：

$$
\frac{\partial L}{\partial w}=\frac{2}{N}\sum_{i=1}^{N}\left(w x_i+b-y_i\right)x_i
$$

$$
\frac{\partial L}{\partial b}=\frac{2}{N}\sum_{i=1}^{N}\left(w x_i+b-y_i\right)
$$

梯度里每一项都是「预测减真实」的误差乘上对应的输入。误差为正说明预测偏大，
就往减小的方向调；误差为负就往反方向调。

### 3. 梯度下降的更新式

$$
w\leftarrow w-\eta\frac{\partial L}{\partial w},\qquad
b\leftarrow b-\eta\frac{\partial L}{\partial b}
$$

η 是学习率，决定每一步走多大。课堂上看损失随参数变化的曲线，讲的就是这个式子的几何含义。

### 4. 为什么课堂上把 b 固定住

同时调 w 和 b，损失是一张二维曲面，画在纸上看不清楚。为了让学生看清「一步步往低处走」，
幻灯片里把 b 固定在最优点，只调 w。此时 L 是关于 w 的二次函数：

$$
L(w)=L_{\min}+c\left(w-w^\ast\right)^2,\qquad
w^\ast=\frac{\sum_i x_i\left(y_i-b\right)}{\sum_i x_i^2},\qquad
c=\frac{2}{N}\sum_i x_i^2
$$

二次函数只有一个最低点，用初中的抛物线就能解释清楚梯度下降。

### 5. 学习率为什么会发散

把更新式代入二次函数，误差会按固定比例缩小或放大：

$$
w_{t+1}-w^\ast=\left(1-\eta c\right)\left(w_t-w^\ast\right)
$$

所以只要 **0 < η·c < 2** 就会收敛，超过 2 就会越走越远。这也是「学习率太大训练会崩」的数学原因。

## 四、术语表

| 术语 | 一句话解释 |
| --- | --- |
| 样本 | 一次观测，表格里的一行 |
| 特征 | 用来预测的输入，记为 x |
| 标签 | 想要预测的目标，记为 y |
| 监督学习 | 训练数据里带着正确答案的学习方式 |
| 参数 | 模型里由训练决定的数，例如 w 和 b |
| 超参数 | 由人设定的数，例如学习率、多项式次数 |
| 损失函数 | 把模型的好坏压缩成一个数的函数 |
| 均方误差 | 误差平方后的平均值，最常用的回归损失 |
| 梯度 | 损失上升最快的方向，反着走就是下降方向 |
| 梯度下降 | 沿着负梯度方向反复小步调整参数的训练方法 |
| 学习率 | 每一步走多远的系数，记作 η |
| 归一化 | 把不同量级的特征缩放到相近范围，便于训练 |
| 训练集 | 用来调整参数的数据 |
| 验证集 | 用来比较模型与调超参数的数据 |
| 测试集 | 只在最后评估一次的数据 |
| 泛化 | 在没见过的数据上的表现 |
| 欠拟合 | 模型太简单，训练和验证误差都大 |
| 过拟合 | 模型把噪声也背下来了，训练误差小、验证误差大 |
| 准确率 | 预测正确的比例，类别不平衡时会失真 |
| 召回率 | 该被抓住的样本里，实际抓住了多少 |
| 精确率 | 被判为某类的样本里，有多少是真的属于这一类 |

## 五、练习与答案

1. **给三个样本 (0, 1)、(1, 3)、(2, 5)，用最小二乘拟合一条直线，MSE 是多少？**
   答案是 y = 2x + 1，三个点都落在直线上，MSE = 0。这题说明：当数据恰好符合线性关系时，
   最小二乘能给出精确解。

2. **如果把学习率从 0.80 改成 0.05，损失曲线会变成什么样？**
   仍然单调下降，但下降得非常慢——8 步之后损失还有 1351.9，远没到最低点。
   现象是「训练看起来在进步，但一直收敛不了」。

3. **训练误差 0.001、验证误差 67.314，说明什么？下一步怎么办？**
   典型的过拟合：模型把 14 个训练点连同噪声一起背下来了。
   下一步是降低模型复杂度（比如把 9 次多项式换回 3 次）、增加数据量，或加入正则化。

4. **一个模型准确率 95%、召回率 0%，能装到车上吗？**
   不能。它只是学会了永远输出多数类（「不需要转向」），一个该转向的时刻都没抓住。
   在机器人上，漏报往往比误报贵得多，所以要看召回率而不只是准确率。

5. **为什么训练前常要把特征归一化？**
   不同特征量级差太多时，损失曲面会变成一个又长又窄的峡谷：在陡的方向上稍微一动就飞出去，
   在平的方向上走半天也不动，很难选到一个对两个方向都合适的学习率。
   把特征缩放到相近范围，曲面接近圆形，一个学习率就能同时照顾所有方向。
