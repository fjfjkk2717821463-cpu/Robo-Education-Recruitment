`assets/` 里的配图不是手绘示意图，而是对一张合成画面真实执行「HSV 阈值分割、形态学开运算、
轮廓提取、质心计算」之后得到的中间结果。运行 `python3 assets/make_figures.py` 可以重新生成，
便于以后替换成真实的摄像头截图。

## 四问回答

### 1. 你在本次任务中使用了哪些 Git 或 GitHub 功能？

- 在 GitHub 上创建远程仓库，并在本地用 `git init` / `git remote add` 建立对应关系；
- 用 `git status`、`git diff` 查看改动，用 `git add` 挑选要提交的文件；
- 分阶段提交：先提交内训选题，再提交幻灯片与配图，最后完善 README，避免一次性上传全部文件；
- 用 `.gitignore` 排除本地构建目录，保证仓库里只留下有意义的成果文件；
- 新建分支 `docs/readme-checklist` 做小修，通过 Pull Request 合并回 `main`，体验了一次协作流程；
- `git push` 推送到远程仓库，并用 `git log --oneline --graph` 检查提交历史。

### 2. 操作过程中遇到了哪些问题？你是如何解决的？

1. **第一次提交时提交者信息是空的。** 先在本仓库里配置 `user.name` 与 `user.email`，
   并使用 GitHub 提供的 `@users.noreply.github.com` 邮箱，避免把真实邮箱写进提交记录。
2. **构建过程中的中间文件差点被一起提交。** 用 `git status` 时发现了一些自动生成的目录，
   于是把它们写进 `.gitignore`，再重新 `git add`，保证提交内容干净。
3. **中文文件名在命令行里容易出错。** 路径统一用引号包起来，并且在推送后到网页上逐个确认
   文件名和目录结构显示正常。
4. **导出的 PDF 里中文全部变成空白。** 原因是转换工具没有加载到中文字体。为转换过程指定了一份
   明确的字体配置，重新导出后中文、代码字体都正常显示，并逐页对照源文件检查了一遍。

### 3. 如果将来需要多名教学部成员共同维护这个仓库，你认为应当如何组织文件与修改流程？

**文件组织**：保持「一类资料一个目录」的结构，例如 `topic/` 放课程方案、`slides/` 放某次内训的
源文件与导出文件、`assets/` 放公共图片。每次内训单独建一个子目录（如 `slides/2026-视觉入门/`），
避免不同年份的资料混在一起。文件名统一写成「主题-版本」的形式，不使用「最终版」「新建文件夹」
这类无法辨认的名字。

**修改流程**：`main` 分支保持可读、可展示的状态，任何修改先开分支，改完后提 Pull Request，
由另一名成员看过再合并。提交信息写清楚「改了什么、为什么改」，一次提交只做一件事。

**长期维护**：公共资源（字体、模板、公共配图）统一放在 `assets/`，避免各人复制多份导致不同步；
对不确定是否还要用的内容，先移到归档目录而不是直接删除；README 里维护一份「资料索引」，
新成员进来看一眼就知道每份资料在哪里、对应哪一次内训。

### 4. 本次纳新题中是否使用了 AI 工具？如果使用，请说明 AI 参与了哪些部分，以及你进行了哪些检查与修改。

**使用的工具**：Codex（AI 编程助手），用于资料整理、方案初稿、配图脚本与幻灯片框架。

**AI 参与的部分**

- 协助把内训选题的想法整理成结构完整的 Markdown 方案；
- 协助编写 `assets/make_figures.py`，生成幻灯片里用到的阈值分割、形态学、轮廓与质心结果图；
- 协助搭建幻灯片的页面骨架与排版，包括流程图、表格和代码页；
- 协助整理本 README 的结构。

**我做的检查与修改**

- 逐页对照幻灯片，把不符合自己讲述习惯的表述改回口语化，并删掉了自己讲不清的内容；
- 核对 OpenCV 的关键事实：`cv2.cvtColor` 的 BGR2HSV 通道顺序、H 的取值范围是 0-179 而不是 0-360、
  红色需要取 H 的两段区间，确认幻灯片里的阈值示例和最小脚本能自洽；
- 逐条检查失效清单里的原因与对策是否真的对应，去掉了一条自己无法解释的条目；
- 重新运行 `make_figures.py`，确认配图里的面积、质心和脚本输出一致，不是手画出来的假数据；
- 检查导出 PDF 的每一页，确认没有文字被裁掉、表格没有串行、代码没有折行错位；
- 确认幻灯片里没有出现我无法在面试中解释的内容。

**AI 没有参与的部分**：选题的方向与取舍、课程对象与课时的判断、失效清单的取舍、最终提交与否的决定。
